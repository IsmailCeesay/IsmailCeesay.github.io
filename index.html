CloudGuard
AI-Powered AWS Security Auditor · Open Source CSPM Tool

CloudGuard scans AWS environments for security misconfigurations across IAM, S3, and security groups then uses AI to explain every finding in plain English with concrete remediation steps. Built with a prompt injection detection layer to prevent malicious input from manipulating the AI analysis.

The Illuminate Education breach exposed 10.1 million students records through a dormant IAM account with no MFA. CloudGuard detects exactly that.

Python AWS Boto3 OpenAI API IAM S3 CloudTrail CSPM
Github README
In December 2021, hackers used credentials from a former employee who had left over three years earlier. No MFA. No dormant account detection. 10.1 million students had their data exposed. CloudGuard flags both on first scan.
Phase 1 IAM, S3, and security group scanning with AI-powered analysis and HTML report. Complete.
Phase 2 Automated remediation. CloudGuard fixes misconfigurations automatically with a fix flag.
Phase 3 Continuous monitoring. Scheduled scans, Slack alerts, always-on AWS service.
Phase 4 Compliance reporting. CIS benchmarks, GDPR, ISO 27001 audit-ready reports.
